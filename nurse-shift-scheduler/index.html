How this works

  1. Add your nurses below, with how many shifts they can work per week, how many hours of rest they need between shifts, and any specific days they've requested off.
  2. Set up your shift types (Morning / Evening / Night are ready to go — edit the times if needed, or add your own).
  3. Enter staffing needs — how many nurses you need for each shift, each day of the week.
  4. Click Generate Schedule. The tool fills the week automatically and fairly, respecting rest rules and weekly limits.
  5. Fine-tune it — drag a nurse's name between shifts, or use the "+ Add nurse" box on any shift. Cells outlined in red don't have enough staff yet.
  6. When you're happy with it, click Print for a wall-ready schedule, or Export CSV to open it in Excel.
